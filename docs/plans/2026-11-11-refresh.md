### Task 2: Theme preference

**Files:** Modify `src/lib/stores/theme.svelte.ts`, `src/app.html`, `src/routes/+layout.svelte`.

- `preference: 'system' | 'light' | 'dark'` from localStorage, `resolved` derived from preference and a `matchMedia('(prefers-color-scheme: dark)')` listener.

### Task 3: Clipboard and share owner

**Files:** Create `src/lib/share/clipboard.ts`, `src/lib/utils/platform.ts`. Modify `src/lib/stores/editor.svelte.ts` (`share()`), `src/lib/components/ProjectList.svelte` (`copyShare`).

- `copyText(value: string | Promise<string>)`: if `ClipboardItem` exists, `navigator.clipboard.write([new ClipboardItem({ 'text/plain': Promise.resolve(value).then(t => new Blob([t], { type: 'text/plain' })) })])` synchronously in the gesture; else await value and `writeText`.
- `share()` split: synchronous part builds the URL promise and calls `copyText` (or `navigator.share` on touch) before any await. Errors: `ShareTooLarge` toast; clipboard failure toast with the URL and a Copy action.
- `platform.ts`: `isMac`, `modKey`, `isTouch` (`matchMedia('(pointer: coarse)')`).

Verify: share in Chrome and Safari copies link; reuse path copies existing link.
